# 内容制作指南

把一课讲义（或教材文法页）做成 `content/lXX.json` 的方法和约定。第 9～11 课都按这里的写法制作，新课照做即可；格式定义见 `web/src/types.ts`。

## 流程

1. **录入原文**：照片放在电脑上的 `sources/LXX/`（不上传）。把讲义或教材上的文型、接续说明、例句原样抄进每个文型的 `list`，补上注音。看不清的地方按句意补全，并在 `source` 里注明。
2. **分组**：按讲义或教材的小节分组（`LXX_①`、`LXX_②`…）。没有小节归属的词汇放进单独一组「ことば」。
3. **写讲解**：每个文型写意思、接续、用法、答题常用搭配、常见错误、自编例句（见下文「文型」）。
4. **出题**：每个文型配接续、辨析、完成句三种题（见下文「练习题」）。
5. **自查**：运行 `npm --prefix web run check`，修到没有报错；再对照文末的清单通读一遍。最好请人（或另一个 Claude 会话）独立审一遍日语和中文。
6. **发布**：推送到 `main`。发布流程会先运行同一个检查，有错就不发布。

## 文件结构

```jsonc
{
  "id": "L11", "title": "第11課",
  "source": "出处说明：照片、录入日期、哪些内容是自编的",
  "groups": [{ "id": "L11_1", "title": "L11_①" }, { "id": "L11_w", "title": "ことば" }],
  "points": [ /* 文型 */ ],
  "items": [ /* 练习题，按文型顺序排列 */ ]
}
```

### 命名

- 文型 id：`课-简短罗马字`，如 `L11-monono`、`L10-tsuideni`。
- 题目 id：`文型id-类型字母序号`，如 `L11-monono-f1`（接续）、`-c2`（辨析）、`-p3`（完成句）。
- 已经发布的 id 不要改：学习记录和复习间隔按 id 保存，改了会丢失进度。修改题目内容可以，改 id 不行。

## 文本标记

| 写法 | 含义 |
| --- | --- |
| `{漢字\|かな}` | 注音。日语里的每个汉字都要注音，按词注（`{一人暮\|ひとりぐ}らし`），不要按字拆开 |
| `＿＿` | 空格（两个全角下划线） |
| `**…**` | 完成句标准答案里填进空格的部分 |
| `A：` `B：` `先生：` `店員：` `客：` `母親：` `子ども：` | 对话的说话人，不加注音，显示时自动换行（可用的名字见 `web/src/components/Blanks.tsx`） |
| `（会議で）` | 场景说明，里面的汉字也要注音 |
| `（程度）` `（自以为）` | 括号里没有假名的中文注释，检查时会跳过 |

- 中文说明里提到的日语词也加注音：「{信|しん}じる・{許|ゆる}す」。
- 文法术语（普通形、ます形、ナA、N）不注音。

## 文型（points）

| 字段 | 写什么 |
| --- | --- |
| `pattern` | 文型名，照讲义写。同形不同义时加中文注释区分：`～つもりだ（自以为）` |
| `kind` | `grammar` 文法；`word` 词汇 |
| `list.form` | 讲义上的接续写法（原文）。没有就省略 |
| `list.example` | 讲义或教材的例句（原文）。多条时写成数组，每条单独显示一行 |
| `meaning` | 一句中文释义，括号里补充语感或使用场合 |
| `form` | 接续，每条「形式 ＋ 文型：例子」，按动词、形容词、名词分开写 |
| `rules` | 用法和限制：前后项要求、搭配、语体，以及与相近文型的区别。每条写一个判断标准，要能用来判对错 |
| `safe` | 答题常用搭配：考试时想不出内容可以直接套用的短语 |
| `traps` | 常见错误：`bad` 错句、`fix` 改法、`why` 原因、`tag` 错误类型 |
| `examples` | 自编例句 2～4 句。不要和本文型完成句的标准答案重复，否则做题前就看到了答案 |

错误类型 `tag`：`form` 接续、`meaning` 意思与用法、`context` 上下文（时态、逻辑）、`register` 语体、`word` 词汇与搭配。

## 练习题（items）

每个文法文型一般配 2～3 道接续、2～3 道辨析、2～3 道完成句；词汇可以少一些。**每道题的正确答案都必须用到本文型**；需要对比的相近文型放进错误选项，而不是当正确答案。

### 接续 `form`：自动判分

```json
{ "id": "L11-monono-f1", "point": "L11-monono", "type": "form",
  "cue": "{簡単|かんたん}だ ＋ ものの", "answers": ["{簡単|かんたん}なものの", "{簡単|かんたん}であるものの"],
  "note": "な形容词：～な／～である＋ものの。" }
```

- `answers` 要列全**所有自然的正确写法**：です体和普通体、「でしょう／でしょ」、「もん／もの」、「～だった＋っけ」等。漏掉一个，学习者写对了也会被判错。
- 汉字和假名两种写法都会自动识别（答案里注了音即可）。答案里写成假名的词（如きれい、にぎやか），学习者也可能打成汉字，最好也注音写成 `{綺麗|きれい}`。
- 输入法常打出的汉字写法（`言う`、`事`、`頂く`、`致す`、`下さい` 等）在 `web/src/lib/answer.ts` 里统一换算；新课用到新的写法时补进去。
- `ask` 用来说明要写哪种形式（过去形、です体、否定等）；`note` 是答完后显示的一句说明。

### 辨析 `choice`：选择题

- 恰好一个 `ok`；每个错误选项都必须是真正的错误（不能「也说得通」），并写明 `why` 和 `tag`。
- 错误选项优先取自常见错误：接续错、意思用错、上下文不衔接、语体不当。
- 题干放不下时，可以把句子整句放进选项，用 `ask` 换掉默认的提示，如「选出用法正确的一句」。

### 完成句 `produce`：按中文写日语

```json
{ "id": "L11-monono-p1", "point": "L11-monono", "type": "produce",
  "prompt": "＿＿ものの、＿＿。",
  "zh": "虽然买了新的词典，但几乎没用过。",
  "hint": "Vた＋ものの",
  "checks": ["第一个空：已经做了 → 过去形：{買|か}った", "第二个空：与预期相反的结果：ほとんど{使|つか}っていない"],
  "models": ["**{新|あたら}しい{辞書|じしょ}を{買|か}った**ものの、**ほとんど{使|つか}っていない**。"] }
```

- `zh` 是整句的中文意思，写到能唯一确定答案：时态、谁做什么、语体（对上司还是朋友）都要能从中文或场景说明看出来。
- `models[0]` 是标准答案，空格以外的文字必须和 `prompt` 完全一致（检查脚本会核对）。只有两种写法同样自然时，才加第二个 `models`。
- 提交后系统逐空比对。和标准答案写法不同的空会标「不同」，但不一定算错，学习者再对照 `checks` 自评。所以 `checks` 要写每个空的判断要点，而不是重复答案。
- `hint` 只写语法提示（如「ます形＋がたい」），不写内容；用了提示的答题不计入掌握程度。
- 空格里尽量少放与本文型无关的难词，生词负担会掩盖语法练习。

### 速测 `quick`：快速排查意思和接续

结构和辨析题相同（`prompt`、`ask`、`options`），`type` 写 `"quick"`，id 以 `-q1`、`-q2`… 结尾。速测题不进入每日练习，只在「测试 › 速测」里抽题；答错的会进入错题练习。每个文法 6 道、每个词汇 3 道，题量多是为了不让学习者靠记住某一道题来答对。

| 编号 | 题型 | `ask` | 写法 |
| --- | --- | --- | --- |
| q1–q3 | 意思辨析 | 选出意思最恰当的一项 | 句中一个 `＿＿`；4 个选项是本文型和另外 3 个文型。干扰项必须**接续上也成立**，只能靠意思排除；优先用意思相近、容易混的文型（本课、前几课或常见 N3／N2 文型） |
| q4–q5 | 接续辨析 | 选出接续正确的一项 | 4 个选项是同一文型的不同接法，差别很小：多或少了 だ／な／の，辞書形、た形、ます形、て形之间的混淆 |
| q6 | 含义理解 | 选出这句话的正确意思 | `prompt` 是用了本文型的整句（不留空）；4 个中文译文中只有一个译出了文型的意思，其余是常见误读 |

- **一定要有迷惑性**：不放无关或荒谬的选项。理想的效果是：没记住意思或接续的人会选错，记住了的人能确定地选对。
- **干扰项必须真的错**：只要母语者在这个句子里能接受，就换掉。「不太自然」不算错。
- **用新句子**：不要重复本文型的例句和其他题目，生词控制在 N3～N2。
- **说明和标签**：每个选项都写 `why`；错误选项标 `tag`（意思题用 `meaning`，接续题用 `form`）。

## 自查清单

- [ ] `npm --prefix web run check` 没有报错。
- [ ] 每道题的正确答案都用到本文型；每个错误选项确实是错的。
- [ ] 接续题列全了自然的正确写法。
- [ ] 完成句的中文和标准答案在时态、人物、语体上一致。
- [ ] 自编例句没有和完成句答案重复。
- [ ] 每个文型至少有一道完成句（常规测试从中抽题）。
- [ ] 每个文法有 6 道、每个词汇有 3 道速测题，干扰项都接续成立、意思上确实是错的。
- [ ] `source` 写明了出处和哪些内容是自编的。
