# 文型道場（考试复习工具）

专门为班级考试复习文法的工具（和按教材系统学习的 `studio/` 分开）。

网页版（手机也能用）：https://dwyaneyao.github.io/bunkei-dojo/

## 功能

| 页面 | 用途 |
| --- | --- |
| 今日 | 选择当前复习的课（或「全部」），开始今日练习：先复习到期的题，再学新文型（每天默认 4 个，可在「我的」里改）。下方依次是待加强文型（可一键「练习错题」）、错误类型统计和各课的掌握概览 |
| 文型 | 按课、按小节列出全部文型，可搜索、按掌握程度筛选；点进去看讲解、做「专项练习」 |
| 按课出题 | 选一课（或全部）出一组题，有两种：**完成句**（每个文型一道，写完对照答案、自评）和**速测**（选择题，快速排查意思和接续）。不计时，可随时退出并接着做，也可以放弃后换一课重新出题 |
| 我的 | 登录同步、考试日期、每日新文型数、目标正确率、外观、导出／导入记录、学习方法说明 |

每个文型有讲解和三种练习：

- **接续**（`form`）：写出接上文型后的形式，自动判分，汉字和假名写法都能识别。
- **辨析**（`choice`）：选出最恰当的填法；错误选项来自常见错误，并说明错因。
- **速测**（`quick`）：每个文法 6 道选择题，分为意思辨析、接续辨析、句子含义三种。干扰项都是容易混淆的文型或接法。不进入每日练习，在「按课出题」里抽题。
- **完成句**（`produce`）：按中文意思用日语填空。提交后逐空对照标准答案，再按检查要点自评。

复习方法：

- **FSRS 间隔复习**：每道题单独安排下次复习时间。
- **交错练习**：不同文型交替出现。
- **换句复测**：完成句答错，会换同一文型的另一句再考。
- **错题练习**：集中重做最近一次答错的题，答对就移出。
- **掌握程度**：只按不看提示、独立答对完成句的记录来判定。

练习中途刷新或退出，当天回来会从原来的位置继续；按课出题的一组题会一直保留到做完或放弃。

## 发布与更新

推送到 `main` 后，GitHub Actions 先运行内容检查（`npm run check`），通过后再构建并发布（`.github/workflows/deploy.yml`）。

每次构建会生成 `version.json`。已打开的页面会检查它：在启动时、切回前台时，以及每隔半小时。发现新版本时，浏览页面直接刷新；练习中只显示「已有新版本 · 刷新」。

## 学习记录与同步

网页版没有服务器，学习记录存在当前浏览器里。在「我的」页面用 Google 账号或邮箱登录后（Firebase Auth），记录会同步到 Firestore 的 `bunkeiDojo/{uid}` 文档（gzip 压缩）。这个 Firebase 项目和 Leon 的其他网站共用，所以每个网站用自己的集合名。

- **何时同步**：登录时、作答停下几秒后、切到后台时，各设备把云端记录合并进来，云端缺的再写回去。合并在事务里进行，两台设备不会互相覆盖；另一台设备写入时会实时收到。
- **代码与权限**：同步代码在 `web/src/lib/cloud.ts`，Firebase 配置在 `web/src/firebaseConfig.ts`。这些配置值本来就是公开的；权限靠 Firestore 规则：每个用户只能读写自己的文档。
- **不登录时**：可以用「导出记录／导入记录」手动合并。导入是合并，不会删掉已有作答。

仓库里不放个人数据：`userdata/`（学习记录）和 `sources/`（原始照片）只留在电脑上，见 `.gitignore`。

## 在电脑上运行

双击 `Japanese Learning` 文件夹里的 `start-exam-review.bat`，或在本文件夹里运行：

```bash
npm --prefix web run dev
```

然后在浏览器打开 http://localhost:5179 。电脑版会把记录同时存进 `userdata/progress.json`，每天自动备份。浏览器和文件里的记录总是合并、不会互相覆盖，开两个标签页也安全；记录文件读不了时，工具只提示、不写入。

想试功能又不想动学习记录时，用测试副本：

```bash
npm --prefix web run dev -- --mode sandbox
```

测试副本用端口 5180，数据存在 `userdata-sandbox/`，用完可以删。

## 目录

| 路径 | 内容 |
| --- | --- |
| `content/lXX.json` | 每课一个文件：文型讲解和练习题（目前第 9～11 课） |
| `docs/content-guide.md` | **内容制作指南**：从讲义照片做成一课的流程、字段写法、出题规则和自查清单 |
| `sources/LXX/` | 原始照片：讲义、教材（内容出处）和班级复习卷（只作题型参考）。不上传 |
| `web/` | 应用源码（Vite + React + TypeScript） |
| `web/scripts/check-content.mjs` | 内容检查：注音、id、选择题、标准答案与题干是否对应等 |
| `userdata/progress.json` | 电脑版的学习记录。不上传 |

## 加新课

按 [`docs/content-guide.md`](docs/content-guide.md) 制作 `content/lXX.json`，然后运行 `npm --prefix web run check`。应用会自动读取新文件；没在首页手动选过课时，首页默认显示最新的一课。
